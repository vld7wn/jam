# Blender и 2D-пайплайн

После очистки старой 3D-версии сохранены:

- `blender_mcp_ultra.zip` — подготовленный аддон carlosh7/blender-mcp;
- `mcp-1.0.3.zip` — прежний аддон;
- `install_ultra_addon.py` — подготовка архива нового аддона;
- `spider_walker_source.py` — исходник аддона Spider Walker;
- `jam2d_pipeline.py` — экспорт анимаций в PNG-спрайтшиты для 2D.

Настройки установленного Blender и MCP-подключения очистка не изменяет.

3D-исходники из `model/` удалены по запросу пользователя. Поэтому значения путей по умолчанию в `jam2d_pipeline.py` больше не существуют. Для нового экспорта нужно явно передать собственные файлы через `--spider-source` и `--human-source`; для экспорта человека с дополнительными клипами требуется соответствующий набор анимаций. Это необязательный инструмент: текущая 2D-игра работает без моделей, рисуя спрайты через Canvas 2D.
